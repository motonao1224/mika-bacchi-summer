# Mika × Bacchi — Summer Festival 2026

美伽ちゃんへ、2026年の深川八幡祭りデートを提案するための
スマートフォンファーストな1ページLPです。

## Local preview

Node.js 22.13以降が必要です。

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いて確認できます。

## Checks

```bash
npm run build
npm test
```
